## 5. دليل الاستخدام المختصر

### الموقع العام

1. افتح الرابط الرئيسي واختر العربية أو الإنجليزية.
2. استخدم اختيار القدرة بالحصان أو الكتالوج للوصول للموديل المناسب.
3. راجع السعر الحالي والسعر قبل الخصم إن وُجدت حملة فعالة.
4. أضف المنتج إلى طلب التكييف أو استخدم واتساب للاستشارة.
5. استخدم صفحات الخدمات لتقديم طلب معاينة أو صيانة أو تركيب.

### تسجيل دخول الموظف

1. يضيف Super Admin بريد الموظف إلى Cloudflare Access.
2. يرسل Super Admin دعوة الموظف من تبويب Users في لوحة الإدارة.
3. يفتح الموظف رسالة الدعوة ويضبط كلمة المرور من رابط الإنتاج، وليس من `localhost`.
4. يدخل إلى رابط لوحة الإدارة ويكمل تحقق Cloudflare بالبريد المسموح.
5. بعد نجاح الدخول، تظهر التبويبات التي يسمح بها دوره فقط.

### التشغيل اليومي للوحة الإدارة

- **Overview:** مراجعة مؤشرات التشغيل السريعة.
- **Prices:** إدخال أو مراجعة ونشر الأسعار وفق الصلاحية.
- **Discounts:** إنشاء الحملة أو تعديلها وربط المنتجات ومراجعة تاريخ البداية والنهاية قبل النشر.
- **Locations:** إنشاء مواقع الخدمة وتعديل المسودات؛ المنشور يتبع دورة مراجعة معتمدة.
- **Warehouses / Stock:** متابعة المخزون والحركات، وعدم التسوية اليدوية دون مستند سبب.
- **Orders:** متابعة الطلبات وحالة الدفع والتنفيذ والإلغاء.
- **Notify:** إدارة الإشعارات التشغيلية المتاحة.
- **Audit:** مراجعة من غيّر ماذا ومتى.
- **Users:** دعوة الموظفين وتعديل الدور أو إيقاف الوصول؛ متاح لـ Super Admin فقط.

## 6. حدود الأدوار المقترحة للتشغيل

- **Super Admin:** إدارة المستخدمين والإعدادات الحساسة والموافقة النهائية.
- **Management:** متابعة الإدارة والتشغيل واتخاذ القرارات التجارية دون منحه صلاحيات Super Admin بلا حاجة.
- **Accounts:** مراجعة الأسعار والتكاليف والمدفوعات والتقارير المالية ضمن السياسات المعتمدة.
- **Sales:** متابعة العملاء والطلبات والأسعار العامة دون الوصول لتكاليف الوكيل الخاصة.
- **Operations:** إدارة المواقع والمخزون والتنفيذ وفق نطاق المنشأة.
- **Marketing:** إدارة الحملات والمحتوى العام فقط.
- **Auditor:** قراءة السجلات والتقارير دون تعديل تشغيلي.

الصلاحية الفعلية تُحسم من سياسات قاعدة البيانات، وليس من إخفاء الأزرار في الواجهة فقط.

## 7. ضوابط تشغيل وأمان إلزامية

- يمنع إرسال كلمات المرور أو مفاتيح Supabase أو Cloudflare في واتساب أو البريد العادي.
- لا تُستخدم مفاتيح Service Role داخل المتصفح أو ملفات `NEXT_PUBLIC_*`.
- لا تُنشر تكلفة الوكيل أو الملاحظات الداخلية في الموقع العام.
- يُراجع سجل Audit بعد تعديل الأسعار أو الخصومات أو المخزون أو الأدوار.
- لا يُلغى طلب دفع ظاهر على أنه captured قبل التحقق من بوابة Paymob إن كانت العملية Live أم Sandbox.
- تُلغى صلاحية الموظف فور مغادرته، مع إبقاء Super Admin نشطًا واحدًا على الأقل.
